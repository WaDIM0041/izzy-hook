# Делаем GitHub Pages деплой автоматическим

## Что нужно сделать

### Шаг 1: Создать токен GitHub
1. Зайди на https://github.com/settings/tokens
2. Нажми **Generate new token (classic)**
3. Выбери scope: `repo` (все галочки) и `workflow`
4. Скопируй токен

### Шаг 2: Пришли мне токен
Просто напиши его сюда в чат.

Я создам репозиторий `izzy-hook`, запушу сайт и включу GitHub Pages — сайт сразу будет доступен по адресу:
`https://ТВОЙ_НИК.github.io/izzy-hook/`
